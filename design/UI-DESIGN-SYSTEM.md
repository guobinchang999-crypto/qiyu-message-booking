# 栖愈微信小程序 UI 设计规范

> 版本：1.0  
> 适用端：微信小程序客户端  
> 技术基线：微信小程序原生框架 + TypeScript + TDesign MiniProgram 1.15.x  
> 视觉基准：本目录 `client-*-v2.png` 共 15 张效果图

## 1. 使用原则

本规范将现有效果图转换为可落地的设计令牌、组件规则和页面约束。视觉实现的优先级固定为：

1. 本规范中的设计令牌与组件规则；
2. 对应页面效果图；
3. TDesign MiniProgram 默认规范。

当三者冲突时，优先保证可读性、触控可用性、安全区和状态反馈，再追求像素级还原。业务流程尚未确定的部分只保留事件接口和 Mock 状态，不自行创造业务规则。

### 1.1 品牌语义

- 品牌名称：栖愈｜推拿·SPA。
- 气质关键词：自然、克制、温暖、安静、东方轻奢。
- 视觉表达：米白底色、深鼠尾草绿、暖木色影像、少量暖金点缀、大留白、细边框。
- 所有门店属于同一品牌体系。客户端不展示门店经营类型。
- 会员、余额、优惠券和套餐的默认文案统一使用“全门店通用”；具体限制由后续业务规则覆盖。

### 1.2 禁止事项

- 禁止使用高饱和科技蓝、霓虹渐变、玻璃拟态和重投影。
- 禁止用整页 PNG 充当真实页面 UI。
- 禁止为普通卡片叠加多层阴影或大面积金色。
- 禁止用颜色作为唯一状态区分，必须同时配合文字、图标或形状。
- 禁止在客户端出现门店经营类型、渠道身份或门店独立会员体系文案。

## 2. 画布、栅格与安全区

### 2.1 尺寸基准

- 设计基准：390 × 822 CSS px，对应效果图比例。
- 开发基准：页面宽度 750rpx，由微信小程序按设备宽度自适应。
- 必测宽度：375px、390px、430px。
- 水平页面内边距：32rpx。
- 内容最大宽度：750rpx；手机端不做居中窄栏。
- 双列内容间距：16rpx；卡片列表间距：24rpx；章节间距：48rpx。

不允许用固定 px 复刻整页坐标。尺寸优先使用 rpx，字体和一像素边框可使用 px；复杂布局使用 Flex/Grid，并允许文字自然换行。

### 2.2 顶部安全区

- 自定义导航页通过 `wx.getWindowInfo().statusBarHeight` 获取状态栏高度。
- 导航内容需要结合 `wx.getMenuButtonBoundingClientRect()` 与胶囊按钮垂直对齐。
- 导航栏内容高度默认 88rpx，不包含状态栏。
- 返回、收藏、通知等按钮触控区不得小于 88rpx × 88rpx。
- 标题过长时单行省略，左右各预留至少 96rpx，避免与胶囊按钮重叠。

### 2.3 底部安全区

- 底部操作栏和 TabBar 使用 `env(safe-area-inset-bottom)`；不支持时由系统信息计算兜底。
- 固定操作栏内容高度 112rpx，另加底部安全区。
- 页面滚动区域底部必须预留“操作栏高度 + 安全区 + 24rpx”，禁止内容被遮挡。

## 3. Design Tokens

所有页面和业务组件必须引用语义化令牌，不得散落硬编码颜色与尺寸。建议在 `styles/tokens.wxss` 中定义并在 `app.wxss` 引入。

### 3.1 色彩

| Token | 色值 | 用途 | 禁止用法 |
|---|---:|---|---|
| `--qy-color-brand` | `#3B533E` | 主按钮、选中态、重点数字、品牌图标 | 不用于大面积正文背景 |
| `--qy-color-brand-pressed` | `#304535` | 主操作按压态 | 不作为常态色 |
| `--qy-color-brand-light` | `#E7ECE5` | 轻量选中背景、成功提示背景 | 不承载低对比正文 |
| `--qy-color-page` | `#F4F0EC` | 页面主背景 | 不替代纯白弹窗表面 |
| `--qy-color-surface` | `#FBF8F5` | 卡片、列表、底部栏 | 不与页面背景无边界叠放 |
| `--qy-color-elevated` | `#FFFFFF` | Modal、Toast、浮层 | 不用于所有普通卡片 |
| `--qy-color-text-primary` | `#20231F` | 标题、正文、价格 | 禁止降低透明度到不可读 |
| `--qy-color-text-secondary` | `#666A66` | 辅助信息、说明 | 不用于核心操作文本 |
| `--qy-color-text-placeholder` | `#9A9B97` | 占位符、失效信息 | 不用于可点击文本 |
| `--qy-color-border` | `#D7D0C8` | 卡片、输入框、次按钮边框 | 禁止多重描边 |
| `--qy-color-divider` | `#E6DFD7` | 列表分隔线 | 不作为强调色 |
| `--qy-color-gold` | `#B28A57` | 会员等级、会员价、少量徽标 | 禁止用作主按钮 |
| `--qy-color-gold-light` | `#F2E9DD` | 金色标签浅背景 | 不承载大段文字 |
| `--qy-color-success` | `#3F6B4F` | 成功、营业中、可预约 | 不替代品牌主色的全部场景 |
| `--qy-color-warning` | `#B7793E` | 即将约满、待处理 | 不用于错误状态 |
| `--qy-color-error` | `#C25B52` | 错误、取消、危险操作 | 禁止用于普通价格 |
| `--qy-color-info` | `#456B73` | 中性通知 | 禁止大面积使用 |
| `--qy-color-disabled` | `#C9C7C2` | 禁用文字和图标 | 必须配合禁用背景 |
| `--qy-color-disabled-bg` | `#EEECE8` | 禁用控件背景 | 禁止显示为可点击 |
| `--qy-color-mask` | `rgba(24,28,24,.48)` | Modal/Drawer 遮罩 | 不覆盖 Toast |

状态色必须保留统一语义：绿色为成功/可用，暖棕为临界/提醒，红色为错误/危险，灰色为不可用。

### 3.2 字体

```css
/* 正文 */
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
  "Helvetica Neue", Arial, sans-serif;

/* 装饰性标题；仅用于页标题、章节标题和结果标题 */
font-family: "Songti SC", "STSong", "Noto Serif SC", serif;
```

- Logo 不使用文本临摹，使用透明背景品牌图片资源。
- Android 宋体回退可能存在差异，因此装饰性标题禁止依赖极细字重。
- 正文默认字重 400；强调 500；按钮 500；不使用 700 以上粗黑。
- 金额与验证码使用等宽数字特性；不能依赖时使用系统无衬线并设置适度字距。

| Token | 字号/行高 | 字重 | 用途 |
|---|---:|---:|---|
| `--qy-font-display` | `48rpx / 68rpx` | 500 | 成功标题、品牌氛围标题 |
| `--qy-font-page-title` | `36rpx / 52rpx` | 500 | 页面标题 |
| `--qy-font-section` | `34rpx / 48rpx` | 500 | 章节标题 |
| `--qy-font-card-title` | `32rpx / 46rpx` | 500 | 门店、项目、技师名称 |
| `--qy-font-body` | `28rpx / 42rpx` | 400 | 正文、表单、列表主文案 |
| `--qy-font-secondary` | `26rpx / 38rpx` | 400 | 辅助信息 |
| `--qy-font-caption` | `24rpx / 34rpx` | 400 | 标签、注释、时间说明 |
| `--qy-font-price` | `44rpx / 52rpx` | 500 | 主价格 |
| `--qy-font-code` | `56rpx / 68rpx` | 500 | 六位签到码 |

正文最小字号不得低于 22rpx。重要规则、价格、预约时间不得仅使用 caption 级别。

### 3.3 间距

采用 4px 基础网格，开发中使用以下离散值：

| Token | 值 | 常见用途 |
|---|---:|---|
| `--qy-space-1` | `8rpx` | 图标内部微间距 |
| `--qy-space-2` | `16rpx` | 标签间距、紧凑内容 |
| `--qy-space-3` | `24rpx` | 卡片内部元素、列表间距 |
| `--qy-space-4` | `32rpx` | 页面边距、标准卡片内边距 |
| `--qy-space-5` | `40rpx` | 大型内容组 |
| `--qy-space-6` | `48rpx` | 章节间距 |
| `--qy-space-8` | `64rpx` | 结果页模块间距 |
| `--qy-space-10` | `80rpx` | 大留白 |

### 3.4 圆角、边框和阴影

| Token | 值 | 用途 |
|---|---:|---|
| `--qy-radius-xs` | `8rpx` | 小标签 |
| `--qy-radius-sm` | `12rpx` | 输入框、次按钮 |
| `--qy-radius-md` | `16rpx` | 标准按钮、列表卡片 |
| `--qy-radius-lg` | `24rpx` | 会员卡、结果卡、Modal |
| `--qy-radius-round` | `999rpx` | 头像、状态点、圆形按钮 |
| `--qy-border-thin` | `1px` | 常规描边、分隔线 |

- 普通卡片优先用边框和背景区分，不加阴影。
- 浮层阴影：`0 16rpx 48rpx rgba(48, 42, 35, .12)`。
- 底部固定栏可使用向上阴影：`0 -8rpx 24rpx rgba(48, 42, 35, .06)`。

### 3.5 层级

| 层级 | z-index | 内容 |
|---|---:|---|
| 页面内容 | `0–9` | 图片、卡片、列表 |
| 吸顶导航/Tab | `100` | Navbar、Tabs |
| 底部操作栏/TabBar | `200` | 固定操作 |
| Drawer/Popup | `600` | 选择器、筛选 |
| Modal | `800` | 二次确认、结果反馈 |
| Toast/Loading | `1000` | 全局即时反馈 |

## 4. 图片与图标

### 4.1 图片

- 首页 Hero：建议 16:9 至 2:1，裁切中心偏右，文字叠加区域保持低细节。
- 门店封面：4:3 或 1:1；同一列表必须统一比例。
- 服务项目列表：4:3；详情页 Hero：16:9。
- 技师肖像：3:4，头像：1:1。
- 图片使用 WebP/JPEG，按显示尺寸提供 2x 资源；列表缩略图建议单张不超过 200KB。
- 使用 `mode="aspectFill"`，禁止拉伸；必须提供加载失败占位图。
- 长列表图片启用 `lazy-load`，首屏关键图可预加载。
- 不从效果图中裁切含文字、按钮或图标的区域作为开发素材。

### 4.2 图标

- 优先使用 TDesign Icons 或同风格线性 SVG。
- 标准描边视觉约 1.5px，端点圆润，禁止混用填充厚重图标。
- 常规图标 40rpx；导航图标 48rpx；辅助图标 32rpx；结果图标 128–160rpx。
- 激活态可使用品牌绿填充，未激活态使用次级文字色。

## 5. 基础组件规范

### 5.1 Navbar

- 内容高度 88rpx，背景使用页面色或表面色。
- 标题居中，使用 page-title 或 body 强调样式；同一流程保持一致。
- 返回按钮位于左侧，点击热区至少 88rpx。
- 右侧动作最多两个；超过两个进入更多菜单。

### 5.2 TabBar

- 四项固定：首页、预约、订单、我的。
- 内容高度 104rpx，加底部安全区；上方使用 1px 分隔线。
- 图标 48rpx，文字 22–24rpx；激活态使用品牌绿。
- 每一项点击热区均分整行，禁止只让图标本身可点击。
- 由 `custom-tab-bar` 统一实现，页面不得复制四套底栏代码。

### 5.3 Button

| 类型 | 高度 | 样式 | 场景 |
|---|---:|---|---|
| Primary | `96rpx` | 品牌绿底、白字 | 每个视图唯一主操作 |
| Secondary | `88–96rpx` | 透明/表面底、品牌绿边框 | 导航、联系、次操作 |
| Text | `80rpx` | 无边框、品牌绿文字 | 修改、查看详情 |
| Danger | `88rpx` | 错误色文字或浅错误背景 | 取消、退出登录 |
| Icon | `88rpx` 热区 | 透明背景、线性图标 | 返回、收藏、分享 |

- 圆角 16rpx；按钮左右内边距至少 32rpx。
- 主按钮按压态使用 `brand-pressed`；按压反馈 100–180ms。
- 加载态显示 Spinner 并锁定重复提交。
- 禁用态使用 disabled/disabled-bg，禁止仅降低透明度。
- 同一固定操作栏最多一个实心主按钮。

### 5.4 Card

- 背景 `surface`，边框 `border`，圆角 16rpx；大型会员卡可用 24rpx。
- 标准内边距 24–32rpx；卡片之间 24rpx。
- 整卡可点击时必须提供箭头或明确操作文案。
- 卡内存在独立按钮时，整卡点击与按钮点击不得冲突。

### 5.5 Search、Input 与 Form

- 搜索框高度 88rpx，圆角 12rpx，左侧 40rpx 搜索图标。
- 普通表单行最小高度 104rpx；标签、输入值和错误提示层级清晰。
- 必填项使用语义文字或星号，不能只靠红色。
- 输入错误在字段下方显示 24rpx 错误说明，并聚焦第一个错误字段。
- 手机号、验证码、人数和金额使用对应键盘类型。
- 验证码按钮在倒计时期间禁用，并显示剩余秒数。

### 5.6 Tabs、Segmented 与 Tag

- Tabs 高度 88rpx，激活下划线 4rpx × 40rpx，使用品牌绿。
- Segmented 高度 72–80rpx，选中态边框与文字同时变化。
- Tag 高度 40–48rpx，圆角 8rpx；同一卡片最多展示 3 个，超出用“+N”。
- 标签只描述属性，不承担主操作。

### 5.7 List Cell

- 最小高度 96rpx，左右内边距 32rpx。
- 主信息左对齐，值或箭头右对齐；多行信息使用 16rpx 间距。
- 分隔线从正文起始位置对齐，不穿过头像或图标。

### 5.8 Modal、Popup、Toast

- Modal 宽度约 600rpx，圆角 24rpx，内边距 40rpx。
- 危险操作必须给出明确对象和后果，按钮顺序为“取消 → 确认”。
- Popup/Picker 支持手势关闭时，也必须保留明确完成按钮。
- Toast 用于轻量结果，1.5–2.5秒自动消失；错误信息需要可重试时不得只用 Toast。
- 全屏 Loading 仅用于无法局部更新的关键动作；普通列表使用 Skeleton。

## 6. 业务组件规范

### 6.1 门店卡片

- 必含：门店名、距离、评分、营业状态、地址/商圈、最近可约时间。
- “常去”只代表用户偏好，不代表门店类型。
- 营业中使用成功色；休息中使用次级文字色；暂停预约使用警告色并说明原因。
- 首页排序固定：常去门店在前，附近门店在后。

### 6.2 服务项目卡片

- 必含：项目名、时长、标准价；存在会员价时以暖金辅助展示。
- 价格主数字使用 price 字号，“¥”缩小一级并基线对齐。
- 项目图片比例、标题行数和价格位置在同一列表中保持一致。

### 6.3 技师卡片

- 必含：头像/肖像、姓名、等级、从业年限、技能、评分、服务次数、指定费、最近可约时间。
- 选中态同时使用品牌边框、选中图标和底部已选摘要。
- “系统自动分配”与“指定技师”为互斥选项。

### 6.4 时间槽

- 建议四列布局，槽位最小高度 96rpx，间距 16–24rpx。
- 可预约：品牌色边框；选中：品牌色实心底；即将约满：暖金边框与提示；已约满：禁用灰。
- 禁用时间不可响应点击，且要保留状态图例。
- 日期横向滚动时，当前选中日期必须自动滚入可视区。

### 6.5 订单与预约状态

| 状态 | 色彩 | 可用操作示例 |
|---|---|---|
| 待支付 | Warning | 继续支付、取消预约 |
| 待到店 | Brand/Success | 查看预约码、联系门店、修改预约 |
| 服务中 | Info | 查看详情、联系门店 |
| 已完成 | Success Light | 再次预约、去评价 |
| 已取消 | Secondary/Error Light | 查看详情、再次预约 |

具体按钮权限由业务规则决定，UI 只接收状态与动作列表，不在组件内部写死流程判断。

### 6.6 预约进度

- 使用水平 Steps 表示“已预约 → 待到店 → 服务中 → 已完成”。
- 已完成节点为实心品牌绿，当前节点为空心品牌绿，未来节点为灰色。
- 异常状态在 Steps 上方单独展示，不篡改历史节点。

### 6.7 二维码与数字码

- 二维码最小视觉尺寸 320rpx，四周保留不少于 32rpx 静区。
- 数字码使用 56rpx 字号和 12–20rpx 字距，支持复制时提供明确反馈。
- 必须展示刷新/过期说明；过期时整体置灰并提供刷新动作。
- 二维码颜色保持高对比，不使用渐变或浅金色。

### 6.8 评分与评价

- 星级触控区至少 64rpx，选中使用品牌绿或暖金，但同页保持一种语义。
- 文本评价显示剩余字数，默认上限 300 字。
- 图片上传展示上传中、成功、失败重试和删除状态。
- 提交期间按钮进入 Loading，成功后显示明确结果反馈。

## 7. 状态与反馈

每个数据页面必须具备以下状态，不允许只有理想态：

### 7.1 Skeleton

- 首次加载列表和详情使用与实际结构相近的骨架屏。
- 骨架动画时长约 1.2–1.6秒；尊重系统减少动态效果设置。
- 已有内容的刷新不退回全页 Skeleton。

### 7.2 空态

- 结构：插图/图标 + 标题 + 一句解释 + 可选主操作。
- 示例：“暂无预约” + “完成首次预约后可在这里查看” + “去预约”。
- 空态不使用负面或责备用户的文案。

### 7.3 错误与弱网

- 局部失败在模块内展示；全页失败才使用全页错误态。
- 错误态包含重试按钮，保留用户已填写的表单内容。
- 网络恢复后允许手动或自动重试，但不得重复创建订单。

### 7.4 禁用与防重复提交

- 主操作发出请求后立即进入 Loading 并禁用。
- 请求失败恢复按钮，并说明是否已创建订单。
- 支付、签到、提交评价等动作需要幂等事件入口。

## 8. 动效

- 页面进入/退出沿用微信原生导航，不自定义大幅位移动画。
- 按压、选中和展开反馈建议 100–240ms。
- Modal/Popup 使用淡入和短距离上移，不使用弹跳。
- 预约成功可使用一次 400–600ms 的描边或淡入动画，不能循环干扰。
- 所有动画不能阻塞主操作，也不能成为状态成立的唯一证据。

## 9. 可访问性与文案

- 触控区域最小 44px × 44px，图标按钮补充 `aria-label` 或可访问名称。
- 正文与背景对比度目标不低于 4.5:1，大字号不低于 3:1。
- 支持系统字体放大时，关键信息允许换行，按钮不得截字。
- 图片提供语义说明；纯装饰图片不重复朗读。
- 文案使用“预约”“到店”“技师”“服务项目”等一致术语。
- 时间统一显示为本地时间，日期格式在同一流程内保持一致。

## 11. TDesign 使用约定

- 优先复用 TDesign MiniProgram 的 Button、Navbar、TabBar、Tabs、Tag、Input、Form、Dialog、Toast、Loading、Skeleton、Upload、Steps 等组件。
- 品牌差异通过主题变量、外层业务组件和受控样式覆盖实现，不复制修改 TDesign 源码。
- 页面中重复出现两次以上的组合结构必须抽为业务组件。
- TDesign 组件属性仅负责展示与事件抛出，预约业务判断放在页面/服务层。
- 官方安装与组件使用参考：[TDesign MiniProgram](https://github.com/Tencent/tdesign-miniprogram)；主题与组件列表参考：[官方文档](https://static.tdesign.tencent.com/miniprogram/)。
